# Muhammad Adnan — research website

Static site (plain HTML/CSS/JS) hosted on GitHub Pages. The publication list and Scholar metrics sync automatically every Monday.

## Structure

```
index.html, research.html, publications.html, links.html, contact.html
assets/css/style.css        styles (light + dark mode)
assets/js/main.js           nav state, Scholar metrics, publication list/search
assets/img/                 portrait and research figures
data/publications.json      generated by the sync — don't edit by hand
scripts/fetch_publications.py
.github/workflows/deploy.yml
```

## One-time setup

1. Create a repo and push these files to the `main` branch.
   For a root URL use the repo name `<username>.github.io`; any other name gives `<username>.github.io/<repo>/`.
2. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
3. Get a free API key at <https://serpapi.com> (100 searches/month; the sync uses 1 per run).
4. **Settings → Secrets and variables → Actions → New repository secret**
   Name: `SERPAPI_KEY`, value: your key.
5. **Actions → "Sync publications and deploy" → Run workflow** to do the first sync.

## How the sync works

- Runs every Monday 03:00 UTC, or on demand via **Run workflow**.
- Fetches Google Scholar profile `IPrRziQAAAAJ` through SerpAPI (publications, citations, h-index, i10-index).
- Adds DOIs from ORCID `0000-0001-9224-3824` where titles match.
- If Scholar is unavailable, it keeps the last Scholar data, or falls back to ORCID if that has more entries.
- If the new list is less than half the old one, it refuses to overwrite.
- Normal pushes deploy the site without spending SerpAPI quota.

To change the schedule, edit the `cron` line in `.github/workflows/deploy.yml`.

## Editing content

- Text lives directly in the HTML files.
- Affiliation links on `links.html`: replace `<span class="item">…</span>` with `<a href="URL">…</a>`.
- Run locally with `python -m http.server` and open <http://localhost:8000> (opening the files directly won't load the publication data).

## Custom domain (optional)

Settings → Pages → Custom domain, then add a CNAME record at your DNS provider.
